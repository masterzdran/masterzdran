### 🧪 DataForger — Synthetic Test Data for .NET

> *Forge realistic test data with ease.* Deterministic, country-aware, clearly synthetic data generators — no real personal information, no network or file access, same seed always produces the same dataset. Targets **.NET Standard 2.0**, thread-safe and DI-friendly.

```csharp
var customer  = Forge.ForCountry(Country.PT).WithSeed(1234).Create<Customer>();
var customers = Forge.ForCountry(Country.BR).WithSeed(42).Create<Customer>(1000);
```
